Telegram reward claims credit $1. Each ReplenishCC account and Telegram account is limited to one claim per rolling 24 hours, and the Telegram display name must contain `ReplenishCC.xyz`. Generated claim codes expire after 10 minutes.

**Why:** The user asked to preserve the existing reward and its limits while changing the claim flow.

**How to apply:** Change how members create or submit a claim code without relaxing the amount, either cooldown, the display-name requirement, or the expiry unless the user explicitly asks.
