The store catalog is for license keys. Members buy admin-listed products using account balance and retrieve delivered keys from their own orders; administrators create product listings and add stock.

Keep the catalog empty until administrators add real products.

The member pages use the existing “Buy Logs” and “My Log Orders” destinations and use “logs” terminology in their customer-facing copy. The administrator stock page is labeled “Log inventory.”

**Why:** The user clarified the product category, requested admin-managed listings and inventory, chose the existing log-page labels, and asked to replace “license” wording on the member pages with “logs.”

**How to apply:** Preserve these page labels when extending the ReplenishCC store; do not pre-populate sample products or expose another member's delivered keys.
