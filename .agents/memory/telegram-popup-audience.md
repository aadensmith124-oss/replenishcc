---
name: Telegram pop-up audience
description: The intended audience for admin-created Telegram channel pop-ups.
---

Admin-created Telegram pop-ups are for signed-in ReplenishCC members only. Each announcement must appear in exactly one format: a Telegram pop-up or the dashboard announcements banner, never both.

**Why:** The user explicitly chose signed-in members rather than all site visitors and asked for announcement formats to be mutually exclusive.

**How to apply:** Keep these pop-ups behind member authentication and out of public routes. Do not render popup announcements in the dashboard banner.
